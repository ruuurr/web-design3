# NEON / СЛОВА — онлайн-кроссворд

Браузерная игра с тематическими кроссвордами, выбором сложности и возможностью играть одному или вместе с другими участниками.

## Технологии

- HTML5
- CSS3
- JavaScript (ES Modules)
- Firebase Authentication
- Cloud Firestore

## Как запустить локально

1. Скачайте и распакуйте проект.
2. Откройте папку проекта в Visual Studio Code.
3. Убедитесь, что все файлы проекта находятся на своих местах.
4. Установите расширение **Live Server**.
5. Откройте файл `index.html` через Live Server.

Одиночный режим доступен без настройки Firebase. Для сетевой игры необходимо настроить Firebase и включить анонимную аутентификацию.

## Функции JavaScript

- Выбор темы и сложности кроссворда.
- Каталог кроссвордов с карточками, примерами вопросов и информацией о сложности.
- Открытие кроссворда на отдельной странице `game.html`.
- Автоматическое размещение слов в сетке с учётом совпадающих букв.
- Отображение вопросов по горизонтали и вертикали.
- Ввод и проверка ответов.
- Подсветка правильно и неправильно заполненных слов.
- Подсчёт очков и отслеживание времени прохождения.
- Сохранение выбранных настроек при переходе к игре.
- Создание игровых комнат и вход по коду без отдельной формы регистрации.
- Кооперативный режим с общей игровой сеткой.
- Соревновательный режим с отдельными ответами участников.
- Синхронизация состояния игровых комнат через Firebase.
- Адаптация интерфейса для мобильных устройств.

## Темы кроссвордов

- **Микс** — вопросы на разные темы.
- **Дизайн и IT** — технологии, программирование и графический дизайн.
- **Природа** — растения, животные и окружающий мир.
- **Космос** — планеты, звёзды и астрономия.
- **Культура** — искусство, музыка, кино и литература.
- **Еда** — продукты, блюда и кулинария.

Для каждой темы предусмотрено три уровня сложности.

## Игровые режимы

- **Одиночный режим** — прохождение кроссворда самостоятельно.
- **Кооперативный режим** — совместное решение одного кроссворда.
- **Соревновательный режим** — самостоятельное заполнение ответов участниками комнаты.

Для создания комнаты выбираются кроссворд и режим игры. Другие участники подключаются по коду комнаты и указывают свой никнейм.

## Структура проекта

- `index.html` — главная страница с каталогом кроссвордов.
- `game.html` — страница прохождения кроссворда.
- `style.css` — стили интерфейса и адаптивная вёрстка.
- `app.js` — игровая логика, работа с сеткой, ответы, очки и взаимодействие с комнатами.
- `firebase-config.js` — параметры подключения Firebase.
- `firestore.rules` — правила доступа к базе данных.
- `firebase.json` — конфигурация для публикации через Firebase CLI.

## Настройка Firebase

Для сетевой игры необходимо:

1. Создать проект в [Firebase Console](https://console.firebase.google.com/).
2. В разделе Authentication включить способ входа **Anonymous**.
3. Создать базу данных Cloud Firestore.
4. Добавить параметры своего Firebase-проекта в `firebase-config.js`.
5. Настроить правила доступа в `firestore.rules`.
6. При публикации добавить домен сайта в список разрешённых доменов Firebase Authentication.

Параметры Firebase Web SDK не заменяют правила доступа к базе данных. Не размещайте в клиентских файлах приватные ключи и данные сервисных аккаунтов.

## Публикация сайта

Проект можно разместить на Vercel или Firebase Hosting.

Для публикации через Vercel:

1. Загрузите проект в репозиторий GitHub.
2. Импортируйте репозиторий на [Vercel](https://vercel.com/).
3. Выберите настройки для статического сайта без дополнительной команды сборки.
4. После публикации добавьте домен сайта в разрешённые домены Firebase Authentication.

Для одиночной игры отдельный сервер не требуется. Для работы сетевых комнат необходимы настроенные Firebase Authentication и Cloud Firestore.
